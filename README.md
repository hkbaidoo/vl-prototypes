# Visible Language homepage prototypes

Two clickable homepage directions for the Visible Language journal, built from the Figma file "Visible Language Website".

- `index.html` is a landing page that links to both.
- `option-1/` is the dark hero carousel direction.
- `option-2/` is the editorial front-page direction (Figma frame Landing_Option 1).

Each folder is plain HTML, CSS and JavaScript, with no build step. Fonts load from Google Fonts.

## Publish with GitHub Pages

1. Create a new **public** repository on github.com, for example `vl-prototypes`.
2. Choose **uploading an existing file** and drag in everything inside this folder: `index.html`, `README.md`, `option-1` and `option-2`. Then commit.
3. Go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, Branch to **main** and folder to **/ (root)**, then save.
4. After a minute or two, the site is live at `https://<your-username>.github.io/vl-prototypes/`.

## Notes

- Sign-in, submission and subscribe forms are simulated. Nothing is sent or stored.
- Article and issue links open the live journal on journals.uc.edu.
- A public repository makes these files visible to anyone. Images include journal covers and article figures.
